# 구름 둥지 · 수학 친구 키우기

5학년 1·2학기 수학 11개 단원 문제가 무작위로 계속 나오는 복습 게임입니다.
알 다섯 개 중 하나(구름 요정 / 아기 토끼 / 아기 강아지 / 아기 고양이 / 아기 용)를 골라, 문제를 맞힐 때마다 친구가 자랍니다.

- 빌드 도구·의존성 없음. `index.html`을 열면 바로 실행됩니다.
- 스마트패드(가로 1180×820 기준) 우선, 세로·휴대폰 화면도 지원합니다.
- 기록은 기기 저장(localStorage)만 씁니다. 서버·이름 입력 없음.

## 시험판 범위 (v1.002)
- 첫 화면은 **친구의 방**: 친구가 돌아다니고, 졸리면 침대로 가고, 누르면 반응해요.
- **오늘의 바람** 3개(먹고 싶은 간식, 가고 싶은 장소, 돌봄)를 들어주면 우정이 올라요.
- **나들이**에서 문제를 풀어요: 간식 만들기(5문제, 단계마다 재료), 산책(6문제, 한 걸음마다 한 문제, 물건 줍기).
- 문제는 11개 단원을 **돌아가며**, 단원 안 유형도 돌아가며 나와요. 틀린 종류는 몇 문제 뒤 다시 한 번.
- 돌보기: 먹이기(끌어서 입에), 거품 목욕, 비눗방울 놀이, 낮잠 / 상태 4가지(배부름·기분·깨끗함·기운)
- 친구 수첩: 좋아하는·싫어하는 간식, 장소, 장식을 직접 해 보며 알아내요. 우정 단계마다 이야기 장면.
- 꾸미기(친구 장식·방 꾸미기·별사탕 주문), 친구가 쓰는 일기
- 성장 1~5단계, 단계마다 말솜씨가 자람 (정식판 10단계 예정)

## 파일
- `js/problems.js` 단원별 문제 생성기 (u11~u16: 1학기, u21~u26: 2학기)
- `js/lines.js` 대사, `js/data.js` 간식·장소·아이템·이야기, `js/art.js` 캐릭터 SVG, `js/scene.js` 방·부엌·산책길·물건 SVG, `js/sound.js` Web Audio 효과음
- `js/app.js` 게임 진행, `js/version.js` 버전 (고칠 때마다 +0.001)
- `credits.html`, `THIRD-PARTY-NOTICES.txt` 출처와 라이선스
